# Credit Card Optimizer
Optimization tool that determines which credit card should be used based on the item chosen for purchase. 

## How to Run 
```
cd /Users/sophiecrane/GitHub/credit-card-optimization
source .venv/bin/activate
./.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
